# Iridium 计划

Rhodium 的轻量 Go 版本：一个网页，管理本机 agent 的会话。单用户，先做 Linux。

## 不做

IM、Bot、终端、组网（Tailscale）、`rh` 命令、槽位模型、定时任务（agent 自己有）。

## 会话

- agent：Claude、Codex、pi、dsh（DeepSeek Harness）。
- 自动发现 agent 自己起的会话，不建立父子关系。
- 首次发现自动归类：拉起者的工作区 → 同目录（或最近上层目录）已有会话的工作区 → 未归类。拖过的不再自动动。
- 结构：工作区 → 目录 → 会话；目录只有一个会话时不显示这一层。
- 工作区按文件夹：一个会话只属于一个工作区。
- 在别处开着的会话只读；那边退出后可在网页接着聊。
- agent 的 Agent 工具子任务算在原会话里。

## 运行

- 每个会话一个托管进程，只做托管，只用文件：命名管道进 stdin，stdout 追加 `out.log`，退出码写 `exit`。`systemd-run --user` 拉起，Iridium 重启不断回合。
- 托管进程与 Iridium 同一个二进制（`iridium hold`）。
- 空闲回收同 Rhodium：默认 1 小时，全局/按会话可改，可关；有后台任务不回收。
- 崩溃续跑、额度续跑：做，设置里各一个开关。
- 平台相关代码单独一层，以后加 Mac。

## 数据

- 会话列表以磁盘为准（agent 记录目录、`~/.claude/sessions/`、`/proc`）。
- 库（SQLite，纯 Go）只存：归属、置顶、归档、改名、待发队列、推送订阅、授权。
- 历史只读 agent 自己的对话记录；托管输出只用于正在打的字、状态、提问、后台任务。
- 提问不进库，现场问 agent；不设超时。
- 实时更新只推“有变化”和草稿增量，页面自己重新拉。
- 配置一个文件，设置页改的就是它。

## 网页

- 包含 Rhodium 网页全部功能（终端除外）。
- 拓扑图：工作区 → 目录 → 会话，不画拉起关系。
- Web Push，默认关。
- 回复里认 `![](路径)`、`[名](路径)`、行内代码里存在的绝对路径：图片缩略图（约 1024px，点开原图），其余下载卡片；视频音频直接放。只给对话里出现过的路径发链接。
- 上传：分块（50MB/块，可续传），单文件默认上限 2GB，可调；放工作目录 `.iridium/uploads/`，内含只写 `*` 的 `.gitignore`；写不进时放状态目录；默认 30 天清理。
- 中英双语：跟浏览器，可改；自写 `t()`，`zh.ts` 为准，`en.ts` 键必须一致；排版按英文长度。

## 认人

- 校验 Cloudflare Access 令牌；没配时只听本机。主机名白名单、同源检查保留。
- Cloudflare 设置指引：以后定。

## 前端

- React + Tailwind 4 + Base UI；从 Rhodium 网页复制逻辑，界面重画。
- 接口类型从 Go 生成；服务器给消息块，前端不懂各家格式。
- 用 Node 构建，产物 embed 进 Go 二进制。

## 风格

- 简洁、轻、磨砂（只给顶栏、输入栏、弹出框、轻提示）；无强调色，标准中性色。
- 小弹出框从按钮处长出；输入框选中没有描边；键盘 Tab 才有焦点圈。
- 统一动效：弹出、收起、发送、重排；减弱动态效果时只淡入淡出。
- 侧栏学 KDJ 的样子：无底色无卡片，留白分组，箭头单独一列，一行截断，只有 agent logo 带颜色，选中只加粗。
- 状态灯（在 logo 右下角）：运行中蓝色呼吸，压缩中蓝黄渐变转动，需要你琥珀，出错红，启动中灰色呼吸，在别处运行蓝色空心环，空闲无灯。
- 少写字：图标和灯代替文字，字放进悬停提示和 `aria-label`，手机长按出字。

## 开发

- 用 Rhodium 的录制（`test/fixtures/`）测驱动和记录解析，不花额度。
- 直接改、跑测试、看截图，不走 spec → issue → PR → 审查。

## 开工前

- 核实：`claude -p` 子进程的 `sessions/` 文件和环境变量；Codex、pi、dsh 的记录位置和拉起者；dsh SDK 能力；Cloudflare 请求大小上限；命名管道托管的故障情形。
- 装 Go（用户目录）。
- 样张：侧栏、对话页、弹出框、轻提示、状态灯、发送动画，中英各一张。
