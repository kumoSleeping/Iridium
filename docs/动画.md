# 布局与动画

对话区和侧边栏里，什么能让内容换位置、变高矮、改滚动位置。调查和后续计划见 `docs/动画调查.md`。

## 原则

1. **动画必须有，而且要精致**；目标是不出错，不是靠不做动画来避免出错。
2. **动画只做一件事：让变化连续。** 用最简单的过渡，多一种动法就多一种出错的方式。
3. **排版永远是最终的样子。** 没有临时高度；动的只有滚动位置、透明度，和换位时的位移。
4. **能动页面的原因逐条登记**（下表）；没登记的高度变化只保持位置，不做动画。
5. **方向确定**：每个原因只准一个方向，一次移动不掉头。

## 对话的滚动（`web/src/chat/stick.tsx`）

一套规则，不猜高度为什么变，不等别的动画。行不加位移，高度不做动画，只改滚动位置。

| 情况 | 怎么处理 |
|---|---|
| 跟随（在最新处）时末尾变高：新消息、正在写的话、步骤列表展开、长文展开、输入框变高 | 滚动位置缓出到底：离底部的距离每毫秒按同一比例缩小，新来的加进去；第一帧就动，只朝底部，不掉头。只有一个节奏：时间常数是三分之一个 `--move`，写出一行就推上去一行，不落后几行。一帧最多按 32ms 算，页面卡住后接着走，不跳 |
| 跟随时末尾变矮：收起步骤、折起长文、输入框变矮 | 不留空位，浏览器把滚动位置收到新的底部，对话当帧跟着落下 |
| 窗格本身变高矮（键盘、窗口） | 直接贴底，不做动画 |
| 屏幕上方或屏幕里的内容变了（图片、晚到的内容） | 浏览器的滚动锚定（`overflow-anchor`）保持看到的不动。没有锚定的浏览器（Safari 26 及更早）由页面自己做：记住屏幕顶上第一行在列里的位置，变了就把滚动位置加回去 |
| 往上翻到顶，补更早的一页 | 两种浏览器都一样：画之前读顶上那一行的位置，画完同一帧把滚动位置加回去（这期间关掉锚定） |
| 是否跟随 | 只由读的人决定：滚轮、手指、按键（PageUp、↑、Home）、拖滚动条往上，就不跟随；回到底部（任何方式）就跟随。页面自己写的滚动位置不改变它。跟随时人在滚（滚轮、手指、按键、拖滚动条，每次动作后 160ms 内），页面不写滚动位置，触控板的惯性和到底的回弹不被打断；松手后接着缓到底。不跟随时下面来了内容，亮“新消息”键；按它：离底部远的先放到底部上方 96px，余下缓出 |
| 打开会话 | 第一帧就在最新处，不做动画；离开时不在底部的，回来时回到原处 |
| 跟随时一次多出超过一屏（窗格高度）：标签页从后台切回、首屏内容晚到、整条长消息 | 直接贴底，不缓动（kumo，2026-11-26：Zen 切回标签页从上滚到底）。标签页在后台时浏览器不出帧、不报高度变化，没有东西在跟；切回前台（`visibilitychange`、`pageshow`）跟随中的当帧贴底。打开时还没有内容的，内容到的那一帧算第一帧 |
| 减少动画（系统设置） | 直接到位 |

`toEnd`：发出消息，回到跟随。`letGo`：跳到引用的消息，不跟随。

### 回访和远处的行（`web/src/chat/channel/lazyrows.tsx`）

长频道有上万个元素，回到它时在切换的那一帧里全部重画（实测 2026-11-27：约 320 条消息、2 万个元素，一个任务 0.6–0.8 秒，降速 4 倍 3 秒以上，没有任何请求）。

| 情况 | 行为 |
|---|---|
| 回到本页开过的会话 | 第一帧只画看得见的和上方一屏半、下方一屏的行；其余是和上次同高的空盒，列的高度、滚动位置、跟随、保位都和全画时一样。之后空闲时由近到远补画，每次约 800px |
| 没开过、宽度变了、行变了 | 该行（或全部）照常画，不用空盒 |
| 空盒快进到视野（拖滚动条、Home、跳到某条消息） | 滚动事件的同一帧里画出来，不出现空白；跳到消息前先全部画出（`drawAllRows`） |
| 离视野两屏以外的行 | 加 `content-visibility: auto` 和量到的高度，浏览器不算它的样式、布局、绘制；近了就去掉（这个属性会裁掉画在行盒外的东西）。最后 3 行不加 |
| 远处的行内容变了、宽度变了、图片到了 | 立刻去掉这个属性重新量，静止 1.2 秒后再加：远处行的高度始终是真的 |

View Transition 开始和结束时各把整页的样式重算一遍，元素越多越久；`data-turn` 的方向变量写在快照的伪元素上，不写在 `html` 上（自定义属性会被继承，整页又多算一遍）。

正在写的字逐字打出来（`chat/typed.ts`）：服务端最多每 120ms 推一次，两次之间按来字的速度每帧吐几个字，落后多就快些，最多落后 300ms；打开时已有的字直接显示。

## 画出来的不换位（kumo，2026-11-24）

对话里已经画出来的行不换位置，新来的只排在最下面。自己发的消息：气泡发出时排在哪（当时页面上已有的消息之后），服务器确认后它的消息就画在哪；这期间进来的别人的话排在它后面，即使服务器给它们的编号更小（`channel/lib.ts` `shownRows`、`placeOf`，位置记在 `channelLog().placed`）。重新打开页面后按服务器的编号排。

## 其余会动的

| 谁 | 管什么 |
|---|---|
| `moves.ts`（`useMoves`） | 标了 `data-flip` 的行换了顺序：从旧位置滑到新位置（位移）。它和上面的跟随用的是不同的属性，互不等待 |
| `moves.ts`（`useLeaving`）、`motion.css` `g-depart` | 走掉的行：位置当帧让出，内容在原处淡出 |
| `Arrive`、`g-arrive`、`g-fade`、`pushIn` | 进场：只改透明度和几像素的升入，不改大小 |
| `motion.ts` `pageTurn` | 会话之间切换（浏览器的 View Transition） |
| `g-unfold`、`g-dialog`、`ui.tsx` `OwnPopup` | 弹窗开关：只过渡透明度和位移缩放，起点是 `@starting-style`，关是 `data-closed`（按下当帧就有），中途再按从当前值掉头。弹窗的布局框从第一帧起不变，不做宽高动画 |
| `g-slide`、`g-stagger` | 弹窗里换页、菜单项依次升入：同样从 `@starting-style` 过渡。换页时弹窗大小在按下那一帧一次变成新页的大小 |
| `sheet.tsx` | 手机底部面板：开关用位移；变高矮（搜索）只移 `translate`：变高时先变高、从下面滑上来，变矮时先滑下去、到位后再变矮 |
| `g-reveal` | 一行自己的展开收起（高度过渡）。对话区里用它的地方列在 `web/test/movers.test.ts` |
| `sidebar.tsx` 侧栏收起、展开 | 不动画，直接切换（kumo，2026-11-26：滑动时两份 [Ir] Iridium 并排、列表被截半）。主区顶栏的 [Ir] 和侧栏头部的在同一位置（左 16px、48px 高的条居中），按下时不动 |

## 规范

1. 组件只画最终状态。要让页面动，用上面已有的；不在组件里新写 `animate()`、会改大小的过渡、或改滚动位置。`web/test/movers.test.ts` 列着现有的每一处，新增一处要在那里加一行并写明理由。
2. 晚到的数据先占位：新加一行、一张卡片时，先回答“数据什么时候到、到之前占多高”。
3. 进场、出场只改透明度和不占位的位移。
4. 位移和透明度的动画不加在高度不封顶的元素上（WebKit 按元素大小备绘制缓冲，整列对话滑动时多占过 1.3 GB）；`moves.ts` 只动看得见的部分（`seen.ts`）。
5. 时间只用 `--move`、`--fade`、`--reveal`。新增时间常数要写明它在等什么；用来让两段动画互相让路的不许加。
6. 减少动画（系统设置）时：位置直接到位，只留淡入淡出。

## 移动记录（`web/src/motionlog.ts`）

每次移动记一条：谁、为什么、多少像素。`window.__moves` 可读。滚动模块记的：`stick.follow`（`grew` 自己来的、`quick` 人的操作，像素是新增的距离）、`stick.pin`（`pane`、`reduced`、`far` 超过一屏、`shown` 切回前台）、`stick.jump`（按键或发送时先放到底部上方）、`stick.keep`（无锚定时补回上方的变化）、`stick.back`（补一页）、`stick.leave`。

## 弹窗的验收（`web/scripts/motion/pop.mjs`）

每个能用脚本打开的弹窗，逐帧：P1 从第一帧起 1500ms 内大小不变（正常、限速 400ms 且入口出现 2 秒后按、限速且入口一出现就按），P3 开关过程中布局框和去掉变换后的位置不变，P2 打开、60ms 时关、120ms 时再开，每次按下后几帧内方向就变，最后是开着。用法同下（`node web/scripts/motion/pop.mjs <dir> [弹窗名…] [--p1] [--p2]`）。

## 验收（`web/scripts/motion/stick.mjs`）

真实页面、假 agent，逐帧（画完之后）记滚动位置、总高、最后一行和屏幕中间一行的位置。

| 场景 | 要求 |
|---|---|
| A 跟随时一个 STREAM 回合 | 中间那行只往上、不掉头；离底部的距离不超过“每次新增的距离按 `--move` 缓出之和”；最后为 0 |
| B 往上翻 600px 时一个回合 | 中间那行每帧 0px，滚动位置不变，亮“新消息”键 |
| C 从输入框发一句 | 同 A；落定后离底部不超过 2px |
| D 点开、收起干活那一行 | 跟随时展开只往上、不掉头；翻上去时被点的那行 ≤1px |
| E 翻到顶补更早的页 | 补进来那一帧，屏幕里的行 0px |
| F 100ms 一条连发 8 条 | 只往上、不掉头，最后在底部 |
| G 加 `--noanchor`（页面用 `?noanchor=1` 关掉浏览器的锚定）再跑 B、E | 同 B、E |
| R 减少动画、O 重新打开、回到原处 | 直接到位；第一帧在最新处；位置不变 |

```
(cd web && npm run build && npm run build:app)
NO_WEB=1 sh scripts/test-deploy.sh up /tmp/irui-stick   # 改了再装：again
node web/scripts/motion/stick.mjs /tmp/irui-stick            # 全部；或只跑几个：A B E

node web/scripts/motion/stick.mjs /tmp/irui-stick --firefox  # Firefox
sh scripts/test-deploy.sh down /tmp/irui-stick
```
