# QQ Bot（官方）

`iridium-qq`：QQ Bot，你和它们的私聊交给 Iridium 的会话。一台机器可以接多个 Bot，各是一个终端。不内置在 Iridium 里，和它同一个 Release 发布，要用时装。

## 怎么装

- 网页：设置 → 终端管理 → + → QQ Bot（官方）。没装就先下载，然后直接出二维码；手机 QQ 扫码，选“创建新机器人”。扫完自动建终端（名字取 Bot 在 QQ 上的名字，不合终端名规则的字去掉、超过 12 字截断，和已有终端重名就加 2、3…；QQ 不给名字时叫 `QQ`。你本人的面板上操作就带 Claude）、启动服务，回到终端列表。之后它和别的 Bot 一样只是列表里的一个终端，没有单独的分组和管理页；在列表里移除它，只停它的服务、删它的配置（别的 Bot 和二进制留着）。再从 + 加一次就多一个 Bot；扫的是已经接上的 Bot，就只更新它（名字、主人不变）。终端可以在网页上改名：Iridium 认 Bot 的终端只按它的 TOKEN，不按名字（改名后旧名被别的 Bot 占了也不会认错）；插件连上 Iridium 时把新名字写回自己的配置。
- 让 agent 做：说“接上 QQ”（已有 Bot 再加一个：“再接一个 QQ Bot”）。它跑 `iridium-qq setup`（再加一个是 `setup --new`），把二维码图片发给你；你扫完告诉它，它再跑一次；TOKEN 要你在网页面板上点同意（写进文件，agent 看不到）。
- 终端里自己跑：`iridium-qq setup`，终端里直接画二维码，扫完一路做完。

## 命令

```
iridium-qq setup [--wait] [--new]      扫码建 Bot、拿 TOKEN、启动服务（没终端时打印二维码后退出，码 2）；--new 已有 Bot 时再加一个
iridium-qq list [--json]               每个 Bot：终端名、主人、服务、连接
iridium-qq status [--json]             一个 Bot
iridium-qq start | stop | restart      服务（restart 只重启在跑的）
iridium-qq logs [-n 行数]              服务日志
iridium-qq pair                        配对码：别的 QQ 号发给 Bot 就成为主人
iridium-qq remove [--all]              停一个 Bot 的服务、删它的配置（TOKEN 用 ir revoke <终端名> 撤销；网页上的“移除”一起做）
iridium-qq run                         前台跑一个 Bot（服务跑的就是它）
```

每个 Bot 一个目录、一个服务（systemd 用户单元 / LaunchAgent `iridium-qq-<AppID>`）。`--bot <AppID>` 指定 Bot；不指定时只有一个就是它，有多个时 start、stop、restart 对全部，其余报错。

## 做什么

- 先选会话，和网页的会话列表一样：底部菜单第一个“会话”（`/use`）先选文件夹（组）；组里先列直接在组目录下的会话，再列子文件夹（`web/`），最后是 `[NEW] 新会话`（再选 agent，就在这里开）；选子文件夹再列它的会话和新会话。已在会话里时，“会话”先打开当前会话所在的文件夹（翻到它那一页）。文件夹里每页最后是“回到上一级”（子文件夹回到它的组）、“回到根目录”（回到选组），在会话里再加“离开当前会话”。没有子文件夹就直接是会话。未归类只有一个子文件夹时直接进去。`/new` 不带参数是选组、选 agent。没选会话时发的消息不进任何会话，回一张“未选择会话”卡片。
- 列表画成树（`├──`、`└──`），不编号。会话一行：`[CC] 名字 9 小时前`（`[CC]` Claude Code、`[GPT]` Codex、`[PI]` pi、`[DSH]` DeepSeek Harness；进行中写“进行中”），当前的加粗。`/ls` 按组画整棵树，最多 30 个会话。
- 离开会话：“会话”卡片最后一项“离开当前会话”，或 `/leave`。之后 Bot 不在任何会话里，网页上也不再标它，发的消息不进任何会话，直到再选一个。
- 切到一个会话，回复带最近 3 轮对话（一条消息）；`/history [轮数]` 看更多（默认 5，最多 10）。格式：`# 近期消息预览`，每轮两行 `[发送者] 消息`、`[CC] 回复`（过长的去掉中间，留开头和结尾），轮与轮之间一条分割线。
- 没被 Bot 指着的会话：它的审批、提问发到跟随发起这一回合的面板的 Bot（网页“终端管理”里 Bot 的菜单“跟随面板”），以及发起它的 Bot 自己，标题是会话名，点了就答，Bot 不换会话；没人跟随就只在网页上。会话自己想找你用 `ir bot "消息"`：Bot 正指着它就是普通回复；否则是一张卡片，“进入会话”或“关闭”。有多个 Bot 时，先找最近进过这个会话的，再找你最后说过话的（还在一小时被动回复窗口里，不耗额度）；`--to` 指定。
- 网页的会话列表里，会话名字后面、时间前面是现在在这个会话里的 Bot：头像和 agent 图标一样大，右下角一个机器人标，最多 3 个，多的写 +N；面板不标。Bot 终端的头像角标统一是机器人（消息、终端管理、用量里也是）。
- 菜单：连上后把 Bot 的底部菜单换成会话、停止、状态、更多（列表、模型、上下文、用量），“/”面板换成 Iridium 的命令（rh 留下的那个面板直接覆盖）。内容没变不重推（QQ 每分钟最多改 5 次）。
- 只做私聊，只转你本人的 QQ 号（扫码的人，自动记下；网页上不用管）；别人发给 Bot 的消息丢掉。要再加一个自己的号用 `iridium-qq pair`。
- 文字、图片、文件、语音（QQ 的转写）进会话；`/new`、`/use` 这些命令照 Iridium 的 Bot 命令走。
- 回复：Markdown（Bot 没开通就改纯文本，记住，一天后再试），长的按 2000 字切。图片按图片发，别的按文件发，QQ 一次最多 20MB。
- 卡片（选会话、提问、审批）：开通了 Markdown 的点按钮；也可以直接回选项的名字（不带 `[CC]` 标、文件夹不带 `/` 也认；重名取第一个）。多个问题的卡片没有按钮，每个问题回一个选项名，逗号隔开。
- 额度：每条你发的消息 1 小时内能被动回 4 条，用完改主动消息，主动也用完就攒着，等你下一条消息时补发。
- 不做：群聊、频道、平台菜单、过程文字（QQ 不能改消息，额度也不够）。

## 和 rh

一个 Bot 只能有一条网关连接。扫码页上标“在线”的 Bot 正被别处（比如 rh）用着，选了就会从那边断开，两边会一直互相挤。给 Iridium 建一个新 Bot；要整个迁过来，先在 rh 那边去掉。

## 文件

都在 `~/.config/iridium-qq/`（`IRIDIUM_QQ_HOME` 可改），每个 Bot 在 `bots/<AppID>/`：`config.json`（AppID、密钥、主人、终端名，0600）、`token`、`state.json`（网关会话、额度计数、待发）、`status.json`。旧版只有一个 Bot，文件直接在目录下、服务叫 `iridium-qq`；新版第一次运行时搬进 `bots/<AppID>/`，服务换成 `iridium-qq-<AppID>`（原来在跑就接着跑）。终端名不变。
