# 前端设计规范

网页（`web/`）的设计规则。动效见 `web/src/motion.css`，文案见 `AGENTS.md`“UI copy”。

## 设置

- **不分二级类**：一个页面上的几项设置直接平铺成一列，不加“权限”“电脑”“能力”这类分组标题（kumo，2026-11-13）。只有成列的对象（登录、连接、应用）才加标题。
- **一行一项**：名字在左，开关或状态在右。状态只写状态（开、关、Linux x86_64），不写解释句。

## 复用

- **优先复用已有板块**：新页面、新一项先找现有的行、列表、卡片、头像，照用；没有合适的再新做，新做的要能被别处复用（kumo，2026-11-13）。
- **弹窗类型全局复用**：弹窗只用已有的几种：设置面板（`g-dialog`）、并排面板（`g-beside`）、弹出菜单（`g-unfold`）、手机底部面板（`g-sheet`）。不为单个功能另做弹窗样式或动画（kumo，2026-11-13）。面板里换页用 `g-slide`。
