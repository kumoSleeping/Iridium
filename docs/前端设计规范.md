# 前端设计规范

网页（`web/`）的设计规则。动效见 `web/src/motion.css`，文案见 `AGENTS.md`“UI copy”。

## 设置

- **不分二级类**：一个页面上的几项设置直接平铺成一列，不加“权限”“电脑”“能力”这类分组标题（kumo，2026-11-13）。只有成列的对象（登录、连接、应用）才加标题。
- **一行一项**：名字在左，开关或状态在右。状态只写状态（开、关、Linux x86_64），不写解释句。

## 复用

- **优先复用已有板块**：新页面、新一项先找现有的行、列表、卡片、头像，照用；没有合适的再新做，新做的要能被别处复用（kumo，2026-11-13）。
- **弹窗类型全局复用**：从某处点开的弹窗一律是 popover：`PopSurface`（`web/src/ui.tsx`），从点开它的那一项展开（`g-unfold`），点外面或 Esc 关，不放关闭键；右键菜单、笔记、公开链接、应用详情都是它。另外只有设置面板（`g-dialog`）和手机底部面板（`g-sheet`）。不为单个功能另做弹窗样式、定位或动画（kumo，2026-11-13）。弹窗里换页用 `g-slide`。

## 禁止（过度设计）

- **不加说明句**：打开开关、进入页面、切换状态之后，不另外显示一句教人下一步怎么做的话（如打开“配对”后出现“在要接入的电脑或程序上运行 ir join 或 ir pair”）（kumo，2026-11-13）。要用的东西直接给出来，放在用它的地方（如电脑组的 + 里给可复制的脚本）。
- **不加分组、标签、弹窗来“整理”几项内容**：见上面“设置”“复用”。
